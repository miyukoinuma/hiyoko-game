# 🐤 ひよこ育て！ (Hiyoko Sodate!)

ごはんを食べてひよこを大きく育てよう！

## 遊び方

- ⬅️➡️ 矢印キーまたはA/Dキーでひよこを移動
- 📱 スマホはタッチで移動
- 🍚🌾🐛 ごはんを食べるとひよこが成長
- 💀 腐ったごはんに当たるとゲームオーバー
- Lv.15でひよこが🐔ニワトリに進化！

## オンラインランキング

dreamlo APIを使用してグローバルランキングに対応。

### セットアップ

1. [dreamlo.com](http://dreamlo.com/dreamlo) でボードを作成
2. `game.js` の `DL_PUB` と `DL_PRI` にキーを設定

## デプロイ (GitHub Pages)

1. このリポジトリをGitHubにプッシュ
2. Settings → Pages → Source を `main` ブランチに設定
3. 数分後にURLが発行されます
